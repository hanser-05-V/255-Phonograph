# 255留音机

255留音机是一个面向 Hanser 粉丝的音乐与故事收藏工具。

项目计划先提供移动端友好的网页版，集中呈现歌曲、直播翻唱、播放列表与 Hanser 故事会；网页版体验稳定后，再复用前端能力发布 Android 应用，并补充可靠的后台播放与系统媒体控制。

## 初步方向

- 音乐馆：歌曲浏览、搜索、收藏、歌单和连续播放
- 故事会：直播切片、相关故事和时间记录
- 管理后台：由维护者上传并整理音频、视频和内容资料
- Android：在网页版基础上提供后台播放、通知栏控制等原生体验

## 当前状态

项目处于产品设计阶段，技术方案与首个版本范围将在讨论确认后补充。
