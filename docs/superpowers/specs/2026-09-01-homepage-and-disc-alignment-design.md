# 255留音机首页与唱片定位修正设计

## 背景

首个 PC 播放器版本已经具备底部迷你播放器、完整播放器、唱片旋转、同步歌词和频谱。实际浏览器检查发现两个需要继续处理的问题：

1. 完整播放器中的唱片整体向下偏移，越过播放器控制区。
2. 收起播放器后的首页只显示品牌标题和底部播放器，缺少音乐与故事内容入口。

本轮同时修复唱片定位，并按已确认的“音乐首页”方案补充首屏内容。

## 唱片偏移根因与修复

封面使用 `transform: translateY(-50%)` 完成垂直居中，浏览器能正确执行。唱片则使用独立的 CSS `translate` 属性进行居中，同时使用 `transform` 动画进行旋转。在当前浏览器中，独立 `translate` 没有产生预期效果，导致唱片的顶部落在容器中线，也就是整体向下偏移约半张唱片。

修复采用两层结构：

- `disc-artwork__disc-positioner`：绝对定位到 `top: 50%`，使用兼容性稳定的 `transform: translateY(-50%)` 负责垂直居中。
- `disc`：放在定位层内部，只负责 `rotate(360deg)` 的播放动画。

定位和旋转不再共用同一个变换属性。唱片播放时旋转、暂停时停在当前角度的现有行为保持不变；不增加任何入场动画。

## 首页结构

首页采用已经确认的方案 A，并按从上到下的顺序组织：

### 1. 顶部导航

- 左侧显示“255留音机”。
- 中间提供“首页”“音乐馆”“故事会”入口。
- 右侧提供歌曲和内容搜索框。
- 首版导航在当前单页内滚动到对应区域，不引入路由系统。

### 2. 今日听歌概览

左侧主卡显示：

- 今天的憨浓度。
- 今日累计听歌分钟数。
- 今日听过的歌曲数量。
- 继续播放按钮。

统计仅保存在当前浏览器本地，不需要账号或服务器。播放器处于播放状态时累计有效播放时长；跨自然日后新建当天记录。歌曲实际播放超过 10 秒后计入当天歌曲数量。

憨浓度采用简单、可解释的首版规则：当天累计听歌 60 分钟达到 100%，计算为 `min(100, round(累计秒数 / 3600 × 100))`。它是趣味展示，不代表用户等级。

### 3. 每日功能区

- “每日憨曲”：根据本地日期从现有歌曲列表中稳定选择一首，同一天刷新页面结果不变；点击后直接切换并播放该歌曲。
- “每日一签”：显示入口、说明“功能筹备中”，保持禁用，不实现随机抽签、签文数据或持久化。

### 4. 精选歌曲

首页不出现“安静时刻”。首版展示：

- 实际存在的歌曲卡片，例如“等火山喷发的小星球”和“初光”。
- “直播翻唱精选”内容集合入口。
- “最近加入”集合入口。

实际歌曲卡可以直接播放。尚无真实数据支撑的集合卡明确显示“持续整理中”或当前数量，不伪造不可用内容。

### 5. Hanser 故事会

展示“故事会精选”“最近更新”和“时间轴”三张预览卡。由于故事内容和切片数据尚未导入，这些卡片显示后续方向与未开放状态，不创建空白详情页。

### 6. 底部播放器

迷你播放器继续固定在页面底部，并与首页内容保持足够的底部间距。首页卡片、每日憨曲和底部播放器统一使用同一个 `PlayerProvider`，不创建新的音频元素或平行播放状态。

## 组件边界

- `HomePage`：组合首页各区域，不直接操作 `HTMLAudioElement`。
- `HomeHeader`：品牌、锚点导航和本地搜索输入。
- `ListeningSummary`：读取今日统计并展示憨浓度、分钟数与继续播放。
- `DailyFeatures`：每日憨曲与禁用的每日一签。
- `FeaturedTracks`：展示和筛选歌曲卡，调用播放器公开的选曲播放命令。
- `StoryPreview`：展示故事会规划入口和未开放状态。
- `useDailyListeningStats`：累计、按日期保存和恢复本地听歌统计。
- `DiscArtwork`：增加定位包装层，将静态居中与旋转动画分离。

播放器公开 API 增加 `playTrack(index)`，供每日憨曲和歌曲卡复用。它负责切换当前歌曲并表达继续播放意图，不能由首页自己改写音频地址。

## 搜索与交互

- 搜索仅匹配当前已有歌曲的标题和歌手，忽略大小写并去除首尾空格。
- 空搜索显示全部可用歌曲。
- 没有匹配结果时显示“没有找到相关歌曲”，不影响当前播放。
- 点击实际歌曲卡后切换并播放；集合卡和未开放卡不会触发播放。
- 键盘播放快捷键和完整播放器行为保持现状。

## 视觉与响应式

- 首页延续当前蓝黑到暖棕的背景和金色强调色。
- 首页内容使用最大宽度容器，不再只把内容贴在左上角。
- 今日概览与每日功能在宽屏时采用 `2:1` 两列；小于 1024px 时垂直堆叠。
- 精选歌曲宽屏四列，中等宽度两列，小屏单列。
- 页面为底部迷你播放器预留空间，任何首页卡片都不能被遮挡。
- 不增加首页入场动画；遵循 `prefers-reduced-motion`。

## 本地数据与异常处理

- 本地统计键包含日期，数据格式异常时回退为当天零记录。
- 浏览器禁止本地存储时，统计仅保存在本次页面会话，播放功能仍然正常。
- 每日憨曲在歌曲列表非空时一定可选；列表为空属于开发配置错误，沿用播放器的非空队列约束。
- 搜索、统计或故事会预览失败均不能中断播放器。

## 测试与验收

- 回归测试重现当前唱片偏移结构，断言定位包装层承担 `translateY(-50%)`，旋转元素不再承担垂直定位。
- 测试 `playTrack(index)` 切歌并开始播放，且仍只使用一个音频元素。
- 测试听歌时长累计、跨日重置、10 秒歌曲计数和 60 分钟憨浓度封顶。
- 测试每日憨曲在同一日期稳定、不同日期可以轮换。
- 测试搜索匹配、空搜索和无结果提示。
- 测试每日一签不可操作且带有“功能筹备中”说明。
- 完整测试套件和生产构建必须通过。
- 浏览器检查首页在 1280×720 和 1920×1080 下没有内容遮挡；完整播放器中的唱片与封面垂直中心一致，唱片不会越过控制栏。

## 完成定义

打开网页即可看到包含今日憨浓度、听歌时长、每日憨曲、每日一签占位、精选歌曲和故事会预览的音乐首页；实际歌曲入口能够控制同一播放器。展开完整播放器后，封面和唱片垂直居中，唱片播放旋转、暂停停住，并且不再侵入底部控制区。
